# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
React 18+ com Vite, TypeScript (`strict: true`), CSS Modules (`*.module.css`) e Design Tokens nativos em CSS, conforme `/reactspecs`.

## Users
Recrutadores técnicos, Tech Leads, Engineering Managers e pares desenvolvedores buscando um Desenvolvedor Front-End com sólida base de engenharia de software (C/C++, SQL, ADS, experiência corporativa prévia no Banco do Brasil) e especialização no ecossistema moderno (React, TypeScript, CSS Modules, Acessibilidade WCAG e integrações com IA Generativa).

## Product Purpose
Apresentar a trajetória, projetos em produção, extensões publicadas na Chrome Web Store, certificações acadêmicas e competências técnicas de Rafael Perroni em uma experiência web interativa, com alto impacto visual, fluidez mobile-first e rigor de engenharia de software.

## Positioning
Desenvolvedor Front-End que une o rigor da lógica estruturada de sistemas e dados (C/C++, SQL, ADS) à excelência de craft e arquitetura de interfaces modernas (React, TypeScript, Design Tokens e WCAG), integrando IA Generativa no fluxo de trabalho para acelerar entregas com precisão.

## Operating Context
Avaliadores navegam pelo portfólio em telas desktop e mobile, inspecionando código-fonte, testando responsividade, explorando demos em produção (Vercel, GitHub Pages, Chrome Web Store) e avaliando a qualidade arquitetural da própria aplicação.

## Capabilities and Constraints
- Single Page Application (SPA) responsiva, com navegação fluida e rotas semânticas.
- Alternância de tema Claro/Escuro sem flash (FOUC), persistido com tokens CSS globais.
- Efeito interativo exclusivo na foto de perfil (canvas dinâmico/efeito de revelação interativo).
- Apresentação organizada em seções: Sobre, Cursos/Bootcamps, Habilidades, Projetos em Destaque, Outros Projetos (Estudos), Extensões Chrome e Contato.
- Carrosséis/Grids táteis e acessíveis com controle por teclado, toque e botões com IDs persistentes.
- Zero bibliotecas de UI inchadas: CSS Modules nativo, tipagem estrita no TypeScript, bundle ultraleve.
- Prevenção total contra XSS (Zero Trust, JSX nativo, validação de URLs seguras e `rel="noopener noreferrer"`).

## Product Principles
1. **O Portfólio é a Prova Técnica:** Cada linha de código, componente e transição demonstra maestria técnica em React e TypeScript.
2. **Craft Visual Impecável:** Interface com hierarquia impecável, micro-interações refinadas, profundidade e tipografia moderna.
3. **Arquitetura Modular (Feature-Driven):** Organização limpa separando apresentação, estado e contratos (Clean Code / Pragmatic Programmer).
4. **Performance & Acessibilidade Nativas:** Sem peso desnecessário, navegação rápida, contraste testado e semântica WCAG.

## Accessibility & Inclusion
- Padrão WCAG 2.1 AA: contraste adequado em ambos os temas, navegação lógica por teclado, estados de foco evidentes e `aria-labels` claros.
