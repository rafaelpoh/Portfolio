# Portfólio de Rafael Perroni

Este é o repositório do meu portfólio pessoal, uma página web estática desenvolvida para apresentar minhas habilidades, projetos e informações de contato de forma profissional e moderna.

## ✨ Funcionalidades Principais

O projeto conta com diversas funcionalidades implementadas para melhorar a experiência do usuário:

- **Tema Claro/Escuro:** Um botão no canto superior direito permite ao usuário alternar entre um tema claro e um escuro. A preferência é salva e aplicada automaticamente.
- **Design Responsivo:** A interface se adapta a diferentes tamanhos de tela, garantindo uma boa visualização tanto em desktops quanto em dispositivos móveis.
- **Navegação com Scroll Suave:** Clicar nos links do menu de navegação (`Sobre`, `Projetos`, `Contato`) rola a página suavemente até a seção correspondente.
- **Galeria de Projetos:** Uma seção dedicada exibe os principais projetos, cada um com:
    - Imagem de preview.
    - Título e descrição.
    - Links para visualizar a aplicação online e para acessar o repositório no GitHub.
- **Botão "Voltar ao Topo":** Um ícone de seta fixo no canto inferior direito aparece para levar o usuário de volta ao topo da página com um clique.
- **Efeito Interativo na Foto de Perfil:** Ao passar o mouse sobre a foto de perfil, um efeito de canvas é ativado, revelando uma imagem alternativa.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Para a estrutura semântica do conteúdo.
- **CSS3:** Para a estilização, layout (Flexbox, Grid) e design responsivo.
    - **Variáveis CSS:** Utilizadas para facilitar a manutenibilidade e a troca de temas.
- **JavaScript (ES6+):** Para toda a interatividade da página, incluindo:
    - Lógica da troca de tema.
    - Efeito de canvas na imagem de perfil.
    - Funcionalidade de scroll suave.

## 🚀 Como Executar

Por ser um projeto front-end estático, não há necessidade de um servidor ou de instalação de dependências. Basta seguir os passos:

1. Clone este repositório:
   ```bash
   git clone https://github.com/rafaelpoh/portfolio.git
   ```
2. Navegue até o diretório do projeto.
3. Abra o arquivo `index.html` em seu navegador de preferência.
