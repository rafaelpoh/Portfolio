Olá, sou o Rafael Perroni

Sou um Desenvolvedor Front-End com formação em Análise e Desenvolvimento de Sistemas. Tenho uma base sólida em HTML, CSS e JavaScript e estou em um processo de aprendizado contínuo para dominar React e Tailwind CSS.

Minha trajetória, que inclui um estágio no Banco do Brasil lidando com bancos de dados e relatórios, me proporcionou uma visão única sobre a importância da estrutura e da organização de dados. Essa experiência fortalece meu trabalho no Front-End, onde a organização do código é essencial.

Estou motivado a transformar minhas ideias em realidade e contribuir para projetos inovadores. Meu objetivo é continuar crescendo na área de desenvolvimento, expandindo minhas competências para além do Front-End e, futuramente, explorando o mundo de React Native para criar aplicativos que resolvam problemas reais.
